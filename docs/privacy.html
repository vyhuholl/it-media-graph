Privacy Policy

Last updated: 26 October 2026

itgraph is a private analytics tool developed and operated by an individual developer (GitHub: vyhuholl). This policy explains what itgraph reads, what it keeps, for how long, and who sees it.

itgraph uses YouTube API Services

itgraph uses the YouTube API Services, specifically the YouTube Data API v3. Data obtained through them is also subject to the Google Privacy Policy: http://www.google.com/policies/privacy.

What itgraph reads from YouTube

Only public data, read with an API key. itgraph never signs in to anyone's YouTube or Google account, does not use OAuth, and has no access to private data. It reads:

  • About channels in its inventory: the channel ID, title, handle, description, declared country and language, public subscriber, video and view counts, whether the subscriber count is shown, and the ID of the channel's uploads playlist.
  • About videos uploaded by those channels: the video ID and the ID of the channel it belongs to, title, description, publication time, duration, live-broadcast state and its scheduled and actual start and end times, and the public view, like and comment counts.

itgraph does not read comments, and it reads no data about viewers, subscribers or commenters.

How long it is kept

  • Data read from YouTube (titles, handles, descriptions, counts) is kept in a separate set of tables. Channel data is fetched again before it is 25 days old. Anything not fetched again within 30 days is deleted, and so is anything YouTube stops returning. It is never included in backups.
  • Statistics (view, like and comment counts, including readings taken at different ages of a video) are kept for at most 30 days. If YouTube accepts itgraph's analytics use case under its Additional policies on derived metrics and data storage, statistics and the scores itgraph derives from them may be kept for up to 36 months. Titles, descriptions and other data stay under the 30-day rule in any case. This page will say so if that happens.
  • itgraph's own records are kept for as long as the channel is in the inventory: the channel ID, and the reviewer's labels for it (kind of channel, language, in or out of scope, and a short note).
  • A request journal records when each request to the YouTube Data API was made, which method, how many quota units it cost and whether it succeeded. It contains no data returned by YouTube.
  • Review files. To label channels, the developer exports a file with channel titles and handles to their own computer. Such a file is deleted once its labels are applied, and itgraph refuses to apply one older than 30 days.
  • Logs name channels and videos by ID only.

How it is used and shared

  • The data is used to decide which channels are in scope and to recognise videos that are doing unusually well compared with the same channel's other videos at the same age.
  • Scores calculated by itgraph are labelled as calculated by itgraph and are always shown alongside the counts YouTube reports. They are never presented as YouTube metrics.
  • Alerts are delivered through the Telegram Bot API to a private Telegram chat whose members are invited by the developer. An alert contains the video title, a link to the video on YouTube, the counts YouTube reports, and itgraph's score. Telegram processes these messages under its own privacy policy.
  • The database runs on a private server reachable only by the developer. Nothing is sold, used for advertising, or shared with anyone else.

Members of the alert chat

itgraph collects no information about the people in its chat. The bot answers only in the one chat it is configured for. When someone marks an alert as useful or not, itgraph records the verdict and the time, not who gave it.

Visitors of this website

This website is a set of static pages hosted on GitHub Pages. It sets no cookies and runs no analytics. GitHub may log visits under the GitHub General Privacy Statement.

Telegram

itgraph also follows public Telegram channels. That part uses no YouTube data: it stores public posts of those channels and their public view, reaction and forward counts, and no data about their readers.

Authorized Data

itgraph does not use Authorized Data: it never asks anyone to grant it access to their account. If it ever did, that access could be revoked at any time through the Google security settings page at https://security.google.com/settings/security/permissions, in addition to asking the developer to delete the data.

Contact

Questions, complaints and requests about this policy or about data itgraph holds on a channel: open an issue at github.com/vyhuholl/it-media-graph/issues.

Changes

When this policy changes, the date at the top changes with it.

itgraph is not affiliated with, sponsored or endorsed by YouTube or Google.
