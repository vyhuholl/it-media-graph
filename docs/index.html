itgraph

A private analytics tool that follows a hand-reviewed set of IT channels and flags the videos and posts their audiences are responding to unusually strongly right now.

Status, October 2026. itgraph has been running for public Telegram channels since summer 2026. The YouTube part is being built on the same approach: the channel inventory is in use; tracking video statistics and YouTube alerts are in development.

What it does with YouTube

  • A reviewed inventory. A list of channels about software development and IT, mostly English-language, with a small number in Russian. A person looks at each channel and labels it: what kind of channel it is, which language it publishes in, and whether it is in scope.
  • Public statistics of new videos. For channels in scope, itgraph reads the public view, like and comment counts of recent uploads several times as each video ages.
  • Alerts. When a video is doing much better than that channel's own videos usually do at the same age, itgraph sends a short message to a private Telegram chat: the video's title, a link to it on YouTube, the counts YouTube reports, and itgraph's score.

itgraph's score is calculated independently by itgraph. It is not a YouTube metric, it is labelled as itgraph's own wherever it appears, and it is always shown next to the counts YouTube reports.

How it uses the YouTube API Services

  • The YouTube Data API v3, authenticated with an API key. Public data only: itgraph never signs in to a YouTube or Google account, does not use OAuth, and does not access anyone's private data.
  • Methods: channels.list for the inventory; playlistItems.list and videos.list for new uploads and their statistics; search.list and channelSections.list for finding channels to review.
  • Data read from YouTube is refreshed or deleted within 30 days and is never included in backups. What itgraph keeps beyond that are its own records: channel IDs and the reviewer's labels. The Privacy Policy has the details.

Access

itgraph is not a public service and has no sign-up. Its alerts go to a private Telegram chat whose members are invited by the developer. The source code is public on GitHub.
